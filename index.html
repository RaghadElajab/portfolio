COMPUTER VISION · HUMANOID ROBOTICS · ROBOCUP

Jersey-Color Classification for RoboCup Humanoid Soccer

Khalifa University Center for Autonomous Robotic Systems (KUCARS) · KU Robot Athletes (KURA)

How can a humanoid soccer robot identify teammates and opponents when communication is delayed, incomplete, or unavailable?

My work focused on the visual classification problem behind team-aware humanoid soccer: detecting nearby robots, isolating the jersey region, and predicting the visible jersey color without hardcoding team identity.

The predicted color is interpreted using the current GameController assignments, producing teammate, opponent, or unknown roles that future navigation, passing, and defensive behaviors can use.

10
GameController jersey colors supported
3
team-role outputs: teammate, opponent, unknown
2
classification paths: ONNX model and HSV fallback
01

Jersey-color pipeline

Used YOLO robot detections to extract torso-focused crops, then deployed an ONNX classifier across the RoboCup GameController jersey-color classes.

02

Reliability & evaluation

Balanced difficult classes, expanded weak viewpoints, and applied brightness and contrast augmentation. Added conservative HSV fallback and an unknown state instead of forcing unsafe predictions.

03

Dynamic team roles

Connected predicted colors to live GameController assignments so the same classifier can identify teammates, opponents, and uncertain detections without hardcoded team labels.

Research context: Reviewed vision-based field-localization literature and integrated-system design to understand how team-role classification can complement spatial awareness. The localization component was primarily literature-review work; my implementation focus was classification.

The implementation was completed within KUCARS/KURA research infrastructure and the source code is not publicly available.

Binary Bomb Reverse Engineering

A systems project that reverse-engineered a compiled binary bomb and reconstructed the logic behind six phases and a hidden secret phase.

  • Traced assembly-level control flow, registers, memory, and helper functions with GDB.
  • Decoded jump tables, recursion, pointer chains, linked lists, and a hidden binary-search-tree challenge.
  • Disassembly: Used objdump to extract the executable’s x86-64 assembly and organize each phase with its helper functions.
  • Dynamic analysis: Set targeted GDB breakpoints, stepped through instructions, and inspected registers and memory to identify every trigger condition.
  • Logic reconstruction: Recovered numeric sequences, jump-table cases, recursive path encodings, pointer-chasing rules, and linked-list ordering constraints.
  • Hidden phase: Traced the post-defusal control path, discovered the secret trigger, and analyzed its binary search tree to complete the final challenge.
